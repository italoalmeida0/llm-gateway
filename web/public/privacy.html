Privacy Policy

Last updated: 2026

1. What we store

  • Account data: email address, display name, password hash (never the password), TOTP secret, and your Google account identifier if you link it.
  • Usage data: for each API request — timestamp, your key, protocol, model, token counts, latency and HTTP status. IP addresses are logged for security auditing.
  • Request content: prompts and model responses are not stored. They transit in memory only while being proxied; only token counts are extracted.

2. What third parties see

  • Upstream LLM provider: receives the content of your requests (prompts) because this service is a proxy. The upstream provider's own privacy policy applies to that data.
  • Google: if you use Google sign-in, Google processes that authentication under its own privacy policy. We only receive your email address and a stable account identifier.
  • Email delivery: transactional emails (invites, password resets, security alerts) are sent through the SMTP service configured by the operator.

3. What we never do

  • We do not sell, rent or share your data with advertisers.
  • We do not run analytics or tracking pixels. This dashboard contains no third-party scripts except Google's sign-in button when configured.
  • We do not store plaintext API keys — only their cryptographic hashes.

4. Retention

Usage aggregates and audit logs are kept as long as the service operates. You may ask the administrator to delete your account and personal data at any time.

5. Security

Passwords are hashed with PBKDF2; gateway API keys are stored as SHA-256 hashes; the upstream provider key is encrypted at rest. Two-factor authentication is available and recommended.
